# FoxHole DB 1.0.1 — Русский

- Обновлены закреплённые источники AdGuard, EasyList и HaGezi: снимки от 29–30 октября 2026 года, проверенные хеши и отчёт о преобразовании.
- Категории DNS включают вредоносные домены, телеметрию производителей, трекеры и рекламу. Сохраняются четыре варианта normal/pro и medium/full.
- Сборщик проверяет возраст исходных снимков, в том числе при использовании готовой папки источников. Новая дата публикации сама по себе не означает обновление списков.
- Если узкое исключение источника невозможно безопасно представить, преобразование останавливается. Рекламное исключение не превращается в глобальное разрешение, снимающее независимую блокировку вредоносных доменов.

Набор подписанных полей schema3 и отдельная совместимая доставка старого DNS не изменены. Перед публикацией сборщик проверяет закреплённый подписанный компилятор Core и подписи всех feeds. Для изменений пройдены 22 точечные проверки и Python-преобразование четырёх вариантов; компиляция и публикация имеют отдельные проверки сборщика.
