# FoxHole DB 1.0.1

- Updated immutable AdGuard, EasyList and HaGezi inputs to October 29–30, 2026 snapshots, with verified content hashes and conversion counts.
- Categorized DNS provides malicious-domain, OEM telemetry, tracker and advertising lists in four normal/pro and medium/full variants.
- The producer now checks upstream snapshot age, including builds using an existing source directory. A new publication timestamp alone does not establish source freshness.
- Narrow source exceptions that cannot be represented safely now stop conversion. Advertising exceptions cannot become a global allow that bypasses an independent malicious block.

The schema3 signed field set and separate legacy DNS delivery are unchanged. The normal producer verifies its pinned owner-signed Core compiler and all feed signatures before publication. Source changes passed 22 focused checks and four-variant Python conversion; compiler and publication validation are separate producer gates.
